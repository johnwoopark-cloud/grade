# 결시 인정점 계산기

고교학점제에서 정기시험이나 수행평가에 참여하지 못한(결시) 경우, 학업성적관리규정 제22조에 따라 **인정점**을 산출하고 과목별 **최종 점수**를 확인하는 계산기입니다.

설치 없이 `index.html`을 브라우저로 열면 됩니다. 입력값은 그 기기의 브라우저에만 저장됩니다.

## 사용법
1. 과목 카드에서 각 항목의 원점수와 평균(과목평균·영역 평균)을 입력합니다.
2. 보지 못한 항목은 **결시**로 바꾸고 사유(질병 80%, 출석인정 100%, 기타)와 그 시험·영역의 평균을 입력합니다.
3. 인정점과 계산식, 최종 점수가 바로 표시됩니다.
4. 반영비율·만점·기본점수가 다르면 **구성 수정**에서 바꿉니다. 과목은 **+ 과목 추가**로 늘릴 수 있습니다.

## 산출 규칙 (제22조)
수행평가 결시는 기본 설정으로 **기본점수(만점의 30%)만** 부여합니다. 화면의 '수행평가 결시 계산'에서 아래 규정 계산식으로 바꿀 수 있습니다.

| 결시 항목 | 기준 점수 | 식 |
|---|---|---|
| 정기시험 | 응시한 정기시험 (⑥-1) | 응시 점수 합 × 결시고사 과목평균 ÷ 응시고사 과목평균 합 × 인정 비율 |
| 정기시험 | 정기시험 점수가 없으면 수행평가 (⑥-2) | 응시 수행 원점수 합 × 결시고사 과목평균 ÷ 응시 수행 영역 평균 합 × 인정 비율 |
| 수행평가 | 다른 수행평가 영역 (⑦ 예시1-1, 예시2) | 응시 영역 원점수 합 × 결시 영역 평균 ÷ 응시 영역 평균 합 × 인정 비율 |
| 수행평가 | 수행평가 점수가 없으면 정기시험 (⑦ 예시1-2) | 기본점수(만점의 30%) + {(배점 − 기본점수) × 응시 정기시험 원점수 합 ÷ 배점 합} × 인정 비율 |
| 모두 없음 | 학업성적관리위원회 심의 (⑧) | 방법 ①~⑤별 참고 점수를 보여주고, 학교에서 정한 값을 직접 입력 |

- 인정점은 소수 셋째 자리에서 반올림해 둘째 자리까지 쓰고, 해당 만점을 넘지 않습니다.
- 교과에서 기준 영역을 정해 둔 경우(⑦ 예시2)는 결시 항목의 "기준으로 쓸 수행평가"에서 해당 영역만 체크합니다.
- 최종 점수 = Σ(점수 ÷ 만점 × 반영비율)

## 구성
- `js/subjects.js` — 기본 과목과 반영비율
- `js/rules.js` — 인정점 산출 규칙과 최종 점수 계산
- `js/ui.js` — 화면
- `tests/rules.test.js` — 규정 캡처의 예시 계산 검증 (`npm test`)

## 스프레드시트 버전
`sheet/결시인정점계산기.xlsx`는 구글 드라이브에 올려 Google 스프레드시트로 열 수 있는 같은 계산기입니다(정기시험 결시 ⑥항, 수행평가 결시는 만점의 30%).
Claude 계정 없이도 공유해 함께 볼 수 있습니다. 다시 만들려면 `python3 sheet/build_sheet.py sheet/결시인정점계산기.xlsx`.
